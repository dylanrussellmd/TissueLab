# Body-wall exchange format 1.0

SurgVid produces the NPZ; TissueLab loads it without importing SurgVid. Coordinates are metres,
+X patient left, +Y cranial, +Z anterior. The arrays contain no Python pickles.

`format_version`: integer array `[1, 0]`. Versionless files use the legacy v0 layout and remain
supported. Unknown major or minor versions fail clearly, asking for a TissueLab update. A future
format change must update both the producer and consumer contract/tests before release.

| Arrays | Meaning |
|---|---|
| `info` | JSON string, scalar or one-element array; case/provenance/report metadata |
| `x`, `tets` | N×3 rest vertices and M×4 positive-orientation tetrahedron indices |
| `tissue_names`, `tet_tissue` | Tissue names and index per tetrahedron |
| `role_names`, `tris`, `tri_role`, `tri_tet` | Boundary roles, triangles, role index, owning tet |
| `mu_t`, `lam_t` | Lamé parameters in Pa per tetrahedron |
| `mem_tris`, `mu_m`, `lam_m`, `th_m`, `fib_m`, `kf_m` | Membrane triangles, material parameters, thickness in metres, 2D fibre directions and stiffness |
| `fixed` | Boolean per vertex; immutable boundary vertices |
| `surface_names` | Names of render surfaces |
| `<name>__verts`, `faces`, `tet`, `w`, `offset` | Each key has `<name>__` prefix: render geometry and tet embedding (4 weights per vertex), rotating rest offset |
| `tether_tets`, `tether_weights`, `tether_area_m2`, `tether_layers` | Optional connections: K×2 tet indices, K×2×4 endpoint weights, K patch areas, K×2 layer names |

Without tether arrays the wall loads with tethering unavailable. `info.tethers` can report
`connections`, `skin_area_m2`, `covered_area_m2` and rejection counts. The producer owns geometry
inference; TissueLab owns the interactive solver and optional experimental material controls.

The repository tests create small synthetic walls from procedural boxes. No patient scans or
patient-derived assets are included. Scarpa's fascia is not generated by this format or plugin;
layer metadata allows future supported geometry to be represented without inventing a membrane.
