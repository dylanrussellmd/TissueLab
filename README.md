# TissueLab

Interactive tissue mechanics for Blender, with a reusable Python solver. Load a CT-derived
body-wall file, grab skin with handles, and explore deformation with estimated grip forces,
an adjustable hard stretch stop, optional skin stiffening and optional subcutaneous tethering.
These controls are experimental and are not patient-calibrated mechanical measurements.

## Install in Blender

Remove the old **Surgvid Tissue** add-on and restart Blender. In **Edit → Preferences → Get
Extensions**, allow online access, open **Repositories → + → Add Remote Repository**, and add:

```
https://raw.githubusercontent.com/dylanrussellmd/TissueLab/main/extensions/index.json
```

Refresh the repository, find **TissueLab**, and install it. In the **TissueLab** sidebar, click
**Install solver (SciPy)** once if needed. Enable the repository's startup update check if
available; use **Check for Updates** to install later releases. Save and stop Live simulation
before updating, then restart Blender and reload your wall.

The native extension targets Blender 4.2+. Its package/feed are validated with Blender 5.2.3's
extension client; that is not a guarantee of interactive compatibility on every platform.

## Load and interact

Load a `body_wall_h*.npz` generated by SurgVid. Place the 3D cursor on the skin with Surface
Project enabled, add a handle, turn Live on and move the handle with G. The hard limit stops
excessive stretch without tearing. Move the handle back to unload. Optional tethering needs a
wall file containing tether geometry; the panel displays coverage and can show the connections.
Strength/slack settings apply when loading the wall. No patient data is uploaded by the add-on.

CT segmentation, body-wall generation, anatomical assets and video compilation remain in
SurgVid. This repository contains the Blender extension, mechanics library and synthetic tests.
Updating the extension does not rebuild wall geometry. See [the exchange format](docs/body-wall-format.md).

## Develop and release

Python 3.11+:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/pytest -q
.venv/bin/python scripts/publish_extension.py
```

The last command stages a deterministic ZIP and checksummed feed under `extensions/` without
publishing. Only explicitly allowlisted add-on files enter the ZIP. The Python package includes
`tissuelab.tissue_pd` (projective dynamics) and `tissuelab.softbody` (reference XPBD solver).
SurgVid pins this library to a release commit so update-feed releases cannot change its bakes.

For a new release, bump both `pyproject.toml` and `tissuelab/blender_addon/blender_manifest.toml`,
commit the source changes on main, then run:

```bash
.venv/bin/python scripts/publish_extension.py --publish
```

The publisher commits and pushes only versioned archives, the index and install instructions.
Existing archives cannot be overwritten, and feed downgrades are rejected. Older archives stay
available. Source updates and Blender extension releases are explicit, separate actions.

## Tether quality checks

Version 0.2.1 adds taut-connection counts, peak estimated tether tension, and a hard-stop
warning. New SurgVid wall builds also expose rest-length ranges and the main reason for
uncovered skin area. See [the validation procedure](docs/tether-validation.md) before
adjusting strength or considering a separate Scarpa's fascia layer.
